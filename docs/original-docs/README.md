## ⚠️ AI向け注意事項

- このディレクトリ以下のファイルは**参照のみ可**
- **編集・削除・新規ファイル作成は禁止**
- 例外: この `README.md` 自体（ディレクトリの索引であり一次資料そのものではない）はAIが編集してよい — 例: 下記ファイル一覧を最新化する場合など
- `docs/product/requirements.md` や `use-cases.md` を作成する際の一次情報源として参照すること
- **既存コードベースへの導入の場合**: 上記の「一次情報源」という位置づけは新規プロジェクト（比較対象が
  他に何も存在しない状態）を前提としている。既にコードが存在するプロジェクトに本ハーネスを導入する場合
  （`SETUP.md` の既存コードベース導入パス）は、現在何が起きているかについてはコードの方が正であり、
  このディレクトリのファイルは突き合わせ用の参考資料になる。いずれの場合も、コードとここにある
  ドキュメントが食い違う場合にどちらか一方を無条件に正しいと扱うことはない——それは（これまでも）
  `.claude/rules/00-global.md` の「ユーザー向け挙動変更には常に承認が必要」によって統制されている:
  食い違いは報告すべき発見事項であり、人間が解消するものであって、どちらか一方を黙って優先することで
  解消するものではない
